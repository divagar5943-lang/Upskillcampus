About This Repository

This repository contains four Python projects developed as part of my Python internship. These projects demonstrate basic Python programming, file handling, database management, and data security concepts.

Projects

1. Quiz Game

A console-based quiz application that asks multiple-choice questions and calculates the user's score.

Features

- Multiple-choice questions
- Answer validation
- Automatic score calculation
- Final score display

Technology: Python

2. Password Manager

A Python application that stores and retrieves account credentials using a database and encryption.

Features

- Store account credentials
- Retrieve saved credentials
- Generate secure passwords
- SQLite database storage
- Encryption using the Fernet library

Technology: Python, SQLite, Cryptography

3. URL Shortener

A Python application that generates short codes for long URLs and stores the mappings permanently in an SQLite database.

Features

- Generate unique short codes
- Save URLs permanently
- Retrieve original URLs using short codes
- View saved URL mappings

Technology: Python, SQLite

4. File Organizer

A Python utility that organizes files into folders based on their file types.

Features

- Identify file extensions
- Create category folders
- Move files into suitable folders
- Organize documents, images, videos, and other files

Technology: Python, "os", "shutil"

Requirements

- Python 3
- SQLite support (included with most Python installations)
- Additional libraries where required by individual projects

For the Password Manager, install the cryptography library:

pip install cryptography

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the required Python file.

Example:

python QuizGame.py

Replace "QuizGame.py" with the filename of another project to run it.

Learning Outcomes

- Python fundamentals and functions
- Conditional statements and loops
- File and folder management
- SQLite database operations
- Basic encryption concepts
- Problem-solving and project development

Conclusion

These projects helped me apply Python programming concepts to practical tasks and improve my understanding of software development.
